# v0.1.1 — 本地游戏库 / Local Game Library

发布日期 / Release date: 2026-10-29

## 简体中文

本版本将 GameDeck 从 UI 原型推进为可使用的本地游戏库。

### 主要更新

- 手动选择 EXE 添加游戏，自动提取图标并异步统计安装目录容量。
- SQLite 持久化保存游戏记录，重启后自动加载。
- 启动游戏时设置安装工作目录，保存最后游玩时间。
- 卡片支持「仅从列表移除」和「彻底删除游戏本体」，永久删除需再次确认完整路径。
- 修复游戏库嵌套滚动：Page 根级接收滚轮，禁用导航宿主的额外滚动包装，保持一个外层滚动容器。
- 游戏数量、总容量、搜索和空列表状态跟随数据更新。
- 改进重复添加、无效路径、文件占用、目录权限和缓存失败的提示。

### 环境与数据

- Windows；从源码构建需要 .NET 8 SDK 8.0.400 或更新的 8.0 SDK。
- 运行框架依赖构建需要 .NET 8 Desktop Runtime。
- 游戏库：`%LOCALAPPDATA%\GameSentinel\data.db`。
- 图标：`%LOCALAPPDATA%\GameSentinel\Covers\`。
- 源码和用户数据分开保存；发布准备中的缓存清理不清空个人游戏库。

### 校验与限制

本地 Release 构建 0 警告、0 错误，14 组集成检查通过。测试仅使用临时数据和受控子进程；滚轮检查包含实际 Wpf.Ui 导航模板中的程序化事件，尚无本次实机鼠标验收记录。

存储清理、备份/恢复、搬家、平台扫描、提权、提醒和实际 HUD 仍为占位功能。永久删除不经过回收站，会移除整个安装目录及其中的存档、模组和其他文件；文件系统删除不是事务，中途失败可能已移除部分文件。

## English

This version turns the GameDeck UI prototype into a usable local game library.

### Highlights

- Import game executables, extract icons, and calculate directory sizes in the background.
- Persist the library in SQLite and reload it after restarting.
- Launch games with the correct installation working directory and save last-played timestamps.
- Remove entries only, or permanently delete game folders after an additional path confirmation.
- Fix nested library scrolling with a Page-root wheel handler and a single outer scroll viewer.
- Keep counts, total size, search results, and empty states synchronized.
- Improve duplicate, invalid-path, locked-file, directory-permission, and cache error feedback.

### Requirements and data

- Windows; .NET 8 SDK 8.0.400 or a newer 8.0 SDK to build from source.
- .NET 8 Desktop Runtime for framework-dependent builds.
- Database: `%LOCALAPPDATA%\GameSentinel\data.db`.
- Icons: `%LOCALAPPDATA%\GameSentinel\Covers\`.
- Source files and personal data are separate. Release-preparation cleanup preserves the user's library.

### Validation and limitations

The local Release build reports zero warnings and errors, and fourteen integration checks pass. Tests use isolated temporary data and controlled subprocesses. Scrolling checks run programmatic input through the actual Wpf.Ui navigation template; physical-mouse acceptance has not been recorded for this build.

Cleanup, backup/restore, migration, platform scanning, elevation, reminders, and a real HUD remain placeholders. Permanent deletion bypasses the Recycle Bin and includes everything in the installation folder, including saves and mods. Filesystem deletion is not transactional, so a failure may leave a partially deleted directory.
